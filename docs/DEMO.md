# Демо-сценарий Localy

Один прогон на 5–7 минут. Ничего не придумываем на ходу: шаги ниже проверены на seed-данных.

## Перед показом

1. `npm run dev` (или `npm run build && npm start` для стабильной картинки).
2. Войти как `platform@localy.kz`, пароль `Localy2026`.
3. Боковое меню → **Сброс демо** (или `/admin#demo-reset`) → «Сбросить демо» → «Да, сбросить».
   Возвращает согласованный seed: бизнесы, клиентов, покупки, бонусы, акции, рассылки, тарифы.
4. Выйти и войти как `owner@localy.kz`.
5. Открыть заранее вкладки: кабинет (`/dashboard`), касса (`/pos`), клиент (`/me`).

Демо-пароль для всех ролей — `Localy2026`. На размещённом стенде он задаётся через `LOCALY_DEMO_PASSWORD`.

## Основной прогон

| # | Шаг | Что открыть | Что говорим |
|---|-----|-------------|-------------|
| 1 | Онбординг | `/onboarding` | Выбираем категорию — Localy подставляет каталог, цикл визита и пороги активности под нишу |
| 2 | Сайт | `/dashboard/site` | Логотип, обложка, цвета, шрифты, каталог, соцсети — справа живой предпросмотр |
| 3 | Публикация | `/dashboard/site` → «Опубликовать» | Сайт сразу доступен на `/b/<slug>` |
| 4 | QR бизнеса | `/dashboard/qr` | Плакаты для кассы, стола и двери; QR ведёт на `/join/<slug>` |
| 5 | Клиент | `/join/<slug>` | Имя, телефон, согласие → код подтверждения. **OTP — демо-код**, он подписан прямо в форме |
| 6 | Покупка | `/pos` | Сканируем QR клиента (или вводим телефон), пробиваем чек |
| 7 | Бонусы | `/pos` и `/me` | Начисление по правилам лояльности, списание выше порога — с подтверждением клиента |
| 8 | Акция | `/dashboard/promos/new` | Цель → сегмент → механика → текст. Справа прогноз: охват, выручка, ROI. **Прогноз — оценка** |
| 9 | Применение | `/pos` | Кассир видит активную акцию и применяет её к чеку |
| 10 | Аналитика | `/dashboard/analytics`, `/dashboard/promos/<id>` | Факт против прогноза, воронка акции, выручка и средний чек |

## Автоматизация и рефералы

- Слоты записи считаются из расписания: `/dashboard/bookings` → «Когда клиенты могут записаться».
  На публичном сайте клиент выбирает свободный слот, занятый взять нельзя.
- Перенос и отмена с причиной — там же; дубли «клиент + услуга + день» подсвечиваются.
- Фоновые сценарии: `/admin` → «Запустить обработчик» или по расписанию
  `POST /api/cron/run` с заголовком `x-localy-cron-secret`. Он запускает отложенные акции,
  закрывает просроченные и рассылает поздравления с днём рождения.
- Рефералы: в `/me` у клиента есть код и ссылка `/join/<slug>?ref=<код>`.
  После первой покупки приглашённого бонусы получают оба; видно в карточке CRM.

## Что честно называем демо

Эти места помечены в интерфейсе плашкой «Демо» — проговариваем так же:

- **Рассылки** (`/dashboard/campaigns`) — аудитория, согласия, антиспам, история и воронка настоящие, доставка симулируется. Сообщения никуда не уходят.
- **OTP** (`/join/<slug>`) — SMS не отправляется, код показывается в форме.
- **Оплата тарифа** (`/dashboard/subscription`) — демонстрационный checkout, реальных списаний нет.
- **Прогноз акции** (`/dashboard/promos/new`) — модель, а не факт; факт появляется после применений на кассе.
- **Сертификаты, депозиты, абонементы** (`/tools/tool_deposits`) — внутренняя модель, деньги не проходят.
- **Каталог инструментов** — рабочие сценарии и переходы в разделы, а не 31 отдельная интеграция.

## Роли для показа

| Логин | Роль | Что показывает |
|-------|------|----------------|
| `owner@localy.kz` | Владелец | Весь кабинет, тариф, сотрудники |
| `admin@localy.kz` | Администратор | Кабинет без тарифа |
| `marketing@localy.kz` | Маркетолог | Сегменты, акции, рассылки, аналитика |
| `cashier@localy.kz` | Кассир | Только `/pos` |
| `platform@localy.kz` | Админ Localy | Платформа, справочники, сброс демо |

## Чек-лист перед выходом на сцену

- [ ] Демо сброшено, в базе нет следов репетиции.
- [ ] Нигде не видно тестовых названий и чужих логотипов.
- [ ] Кассир видит только кассу: `/dashboard` под `cashier@localy.kz` уводит на `/forbidden`.
- [ ] Клиентская навигация (`/me`) не появляется в кабинете бизнеса.
- [ ] Публичная заявка и запись с сайта не создают клиентскую сессию.
- [ ] Пустые сегменты показывают понятную заглушку, а не пустоту.
- [ ] Мобильный вид проверен: главная, онбординг, кабинет, конструктор сайта, публичный сайт, CRM, акции, касса.
- [ ] `npm run build` и `npm run smoke:e2e` зелёные.
